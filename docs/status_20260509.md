## M4 Self-Voice Detection

- **Integration:** M4 detector wired into streaming runtime with frame-level metadata
  (m4_outcome, m4_confidence, m4_buffer_length)
- **F1 benchmark harness:** `scripts/m4_f1_benchmark.py` — deterministic, no hardware
  - 8 synthetic test cases (self_only, world_only, overlap, same_domain_negative, same-domain playback-window negative, room-colored self, device-EQ self, silence_gap)
  - Mock mode (pipeline verify) and --real-ecapa mode (promotion-grade)
  - Exit 0/1 for CI; `--m4-min-buffer-ms` exposes warmup/latency tradeoff
- **Unit tests:** 16 tests for SelfVoiceDetector + M4 attributor integration + expanded benchmark coverage + replay mode tests
- **Base synthetic gate:** prior 5-case `--real-ecapa` audit run passed with aggregate F1=0.971 (criterion F1 >= 0.95)
- **Expanded gate result:** adding a same-domain negative inside the playback window initially dropped `--real-ecapa` aggregate F1 to 0.9058 with 4 false SELF positives. Template-match-gated ECAPA overrides reduced playback-window false positives to 0. Eligible-frame F1 at 500ms is 1.0, proving classifier quality after warmup; default benchmark buffer is now 300ms, where expanded aggregate F1=0.9512, eligible-frame F1=1.0, and same-domain playback-window false positives remain 0.
- **Replay mode:** `scripts/m4_f1_benchmark.py --real-ecapa --replay-dir data/m3_gated_playback_test` replays captured gated-playback audio through the M4 pipeline and scores F1 against frame-record ground truth. On real captured data, M4 produces zero false SELF positives; the main gap is template mismatch from room coloring on true SELF frames, not M4 discrimination quality.
- **ECAPA limitation on captured data:** ECAPA-TDNN embeddings are not discriminative on room-colored captured audio (mean confidence ~0.06 for SELF vs ~0.03 for others). The model was trained on clean VoxCeleb audio and does not generalize to real-room microphone captures. Per-capture room filter fitting improves template match but does not solve the ECAPA embedding gap. Next step: fine-tune ECAPA on room-colored self-captures or use a different embedding model.
- **Gated playback data unsuitable for M4 validation:** In the existing gated playback captures, agent TTS energy (~28 dB) is buried under human speech/room noise. SELF/BOTH/WORLD frames have nearly identical energy profiles, meaning the agent's self-voice is not distinguishable in these captures. Clean agent-only recordings are needed for M4 validation on real captured data.
- **Clean capture script:** `scripts/m4_clean_capture.py` records agent-only TTS playback through the mic loopback and saves agent PCM + captured audio. Used with `--register-from-clean` to fit a per-capture room filter and room-colored self-embedding for M4 replay scoring.

## M5-M6 Self-Model

- **SelfModel:** `packages/pfc/self_model.py` — observes streaming frame logs, maintains
  self-concept subtree in the SAG:
  - `Corollary.agent_voice` — self-attribution evidence (match scores, M4 confidence)
  - `Corollary.speech_patterns` — energy, duration, repair frequency, self-match quality

- **Running statistics:** accumulates across sessions (self-match mean, M4 accept rate,
  interrupt/defer/resume/repair counts)
- **SAG integration:** nodes updated with context after each session; queryable via
  `query_self_concept()` and `summarize()`
