## Architecture

```
Broca TTS → device 5 (Mac mini Speakers) ─┐
                                           ├──→ Mic (device 3) → Attributor → Controller → Decision
Human Speech → device 4 (Ext Headphones) ──┘
```

**Two independent output devices** — TTS and human speech are physically separated, creating genuine acoustic overlap at the mic.

## Auto-Calibration Bootstrap

At startup (or via `--auto-calibrate`):
1. Synthesize known phrase ("I was speaking, then paused.")
2. Play through TTS output, capture through mic
3. Fit room filter on capture (self-only, no oracle)
4. Compute self-relative threshold (50% of self-score)
5. Export filter + metadata to production location

**Script:** `scripts/m3_auto_calibrate.py`
**Output:** `data/m3_broca_room_filter_production.npy` + `.json`

## Components

### 1. ThalamicAttributor (`packages/thalamus/attributor.py`)

**Scoring paths:**
- `match_score` — global xcorr (dry template vs observed)
- `self_match_score_per_frame` — per-frame energy ratio (observed / expected self RMS)
- `room_local_score` — room-colored self-match (production-causal path)

**Room-local scoring:**
- Pre-fitted 64-tap FIR filter maps dry template → room-colored reference
- Filter fitted on dedicated calibration capture (no oracle peeking)
- Threshold: 0.020 (validated on fresh controls, perfect separation)

**Verdict logic:**
- SILENCE → energy below threshold
- SELF → match_score ≥ threshold AND timely AND room_local_score ≥ threshold
- BOTH → playing AND speech detected (but not SELF)
- WORLD → not playing AND speech detected

### 2. AgentiveController (`packages/pfc/agentive_controller.py`)

**States:** IDLE → SPEAK → LISTEN → IDLE

**Key behaviors:**
- SPEAK survives motor-window silence (low-energy frames don't cancel playback)
- Overlap detection: sustained energy ratio > threshold for N consecutive frames
- Post-interrupt resume: returns to IDLE when human speech ends
- Pre-agent defer: suppresses initial output when human already speaking

### 3. M2 Turn Bridge (`packages/pfc/m2_turn_bridge.py`)

Feeds M2 attribution frames to controller, handles output request timing.

### 4. Live E2E Harness (`scripts/m3_live_e2e_harness.py`)

**5 scenarios:**
| Scenario | Expected Behavior |
|----------|-------------------|
| human_early | Interrupt during overlap, resume after |
| human_late | Interrupt near end of utterance, resume |
| human_before | Defer initial output (human already speaking) |
| human_after | No interrupt, no resume (respond phase) |
| overlap_self_first | Interrupt, resume (agent started first) |

**CLI args:**
- `--room-filter PATH` — load pre-fitted room filter (.npy)
- `--room-local-threshold FLOAT` — override auto-detected threshold
- `--both-external-energy-ratio FLOAT` — overlap detection ratio (default 1.2)
- `--both-external-min-frames INT` — consecutive frames for overlap (default 3)
- `--gated-playback` — render physical TTS segments that defer/split around scheduled human windows
- `--gated-resume-delay-ms FLOAT` — delay before resuming gated TTS after human speech

### Metric Modes

M3 now has two validation modes that must not be conflated:

1. **Reflex interrupt/resume mode** — TTS is allowed to overlap with human speech. The controller should detect overlap, interrupt, and resume. Primary metrics are `true_interrupts`, `missed_interrupts`, and `resume_rate`.
2. **Gated suppression mode** — `--gated-playback` physically avoids scheduled human windows by delaying/splitting TTS output. Because overlap is prevented, legacy reflex fields may show `MI=3`, `TI=0`, and `resume=0/3` on overlap scenarios even when gating succeeds. Primary metrics are from `scripts/m3_gated_playback_analyze.py`: `segment_overlap_passed`, `defer_passed`, and `all_suppression_passed`.

**Reference:** `docs/m3_gated_playback_validation_20260508.md`
