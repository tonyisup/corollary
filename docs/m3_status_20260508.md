## Architecture

```
Broca TTS → device 5 (Mac mini Speakers) ─┐
                                           ├──→ Mic (device 3) → Attributor → Controller → Decision
Human Speech → device 4 (Ext Headphones) ──┘
```

**Two independent output devices** — TTS and human speech are physically separated, creating genuine acoustic overlap at the mic.

## Auto-Calibration Bootstrap

At startup (or via `--auto-calibrate`):
1. Synthesize known phrase ("I was speaking, then paused.")
2. Play through TTS output, capture through mic
3. Fit room filter on capture (self-only, no oracle)
4. Compute self-relative threshold (50% of self-score)
5. Export filter + metadata to production location

**Script:** `scripts/m3_auto_calibrate.py`
**Output:** `data/m3_broca_room_filter_production.npy` + `.json`

## Components

### 1. ThalamicAttributor (`packages/thalamus/attributor.py`)

**Scoring paths:**
- `match_score` — global xcorr (dry template vs observed)
- `self_match_score_per_frame` — per-frame energy ratio (observed / expected self RMS)
- `room_local_score` — room-colored self-match (production-causal path)

**Room-local scoring:**
- Pre-fitted 64-tap FIR filter maps dry template → room-colored reference
- Filter fitted on dedicated calibration capture (no oracle peeking)
- Threshold: 0.020 (validated on fresh controls, perfect separation)

**Verdict logic:**
- SILENCE → energy below threshold
- SELF → match_score ≥ threshold AND timely AND room_local_score ≥ threshold
- BOTH → playing AND speech detected (but not SELF)
- WORLD → not playing AND speech detected

### 2. AgentiveController (`packages/pfc/agentive_controller.py`)

**States:** IDLE → SPEAK → LISTEN → IDLE

**Key behaviors:**
- SPEAK survives motor-window silence (low-energy frames don't cancel playback)
- Overlap detection: sustained energy ratio > threshold for N consecutive frames
- Post-interrupt resume: returns to IDLE when human speech ends
- Pre-agent defer: suppresses initial output when human already speaking
- Collision repair: emits a one-shot structured repair cue (`Sorry, go ahead.` by default) on real SPEAK→LISTEN interruptions

### 3. M2 Turn Bridge (`packages/pfc/m2_turn_bridge.py`)

Feeds M2 attribution frames to controller, handles output request timing.

### 4. Streaming Runtime (`packages/pfc/streaming_runtime.py`) [NEW]

Real-time callback loop: VAD → attribution (M4 optional) → controller → TTS gating.

**CLI:** `scripts/m3_streaming_demo.py` (offline replay or live hardware)
**Analysis:** `scripts/m3_streaming_analyze.py`

**5 scenarios:**

| Scenario | Expected Behavior |
|----------|-------------------|
| human_early | Interrupt during overlap, resume after |
| human_late | Interrupt near end of utterance, resume |
| human_before | Defer initial output (human already speaking) |
| human_after | No interrupt, no resume (respond phase) |
| overlap_self_first | Interrupt, resume (agent started first) |

**Feature flags:**
- `--m4-enable` — enable M4 speaker-embedding detector
- `--gated-playback` — enable real-time TTS output gating
- `--tts-chunk-ms` — TTS emission chunk size in ms (default 200)

### 5. Live E2E Harness (`scripts/m3_live_e2e_harness.py`)

Original dual-speaker replay harness with pre-planned TTS segments and post-hoc analysis.

**Metrics modes:**

M3 now has two validation modes that must not be conflated:

1. **Reflex interrupt/resume mode** — TTS is allowed to overlap with human speech. The controller should detect overlap, interrupt, and resume. Primary metrics are `true_interrupts`, `missed_interrupts`, and `resume_rate`.
2. **Gated suppression mode** — `--gated-playback` physically avoids scheduled human windows by delaying/splitting TTS output. Because overlap is prevented, legacy reflex fields may show `MI=3`, `TI=0`, and `resume=0/3` on overlap scenarios even when gating succeeds. Primary metrics are from `scripts/m3_gated_playback_analyze.py`: `segment_overlap_passed`, `defer_passed`, and `all_suppression_passed`.

**Reference:** `docs/m3_gated_playback_validation_20260508.md`

## Streaming Runtime Results

Streaming validation is now split into two evidence layers:

1. **Behavior gate:** `scripts/m3_streaming_acceptance.py` injects synthetic attribution frames to validate online controller/TTS-gate behavior without room-acoustic ambiguity.
   - pre-agent WORLD speech defers TTS at request time
   - overlap BOTH speech interrupts TTS
   - collision repair emits exactly one structured `Sorry, go ahead.` cue on the interrupt
   - optional repair audio plays after LISTEN, before the deferred original utterance resumes
   - gated TTS position is held while LISTEN, not silently consumed
   - deferred/interrupted TTS resumes and completes
2. **Offline audio replay smoke:** the same acceptance script replays all 5 saved gated hardware captures from `data/m3_gated_playback_test` through the streaming callback/logging path.
   - validates VAD/attribution/controller/log plumbing on real captured audio
   - intentionally not used as the overlap behavior gate because room-colored captures can under-match dry TTS templates in local xcorr

## Collision Repair Results

Collision repair is now implemented as structured controller policy output plus optional suppressible repair-audio playback in the streaming runtime.

- **Controller field:** `ControllerDecision.collision_repair_text`
- **Default cue:** `Sorry, go ahead.`
- **Streaming log fields:** `collision_repair_text`, `output_source`, `repair_position_s`, `repair_playing`, `repair_completed`
- **Summary metrics:** `collision_repair_events`, `repair_played_frames`, `repair_audio_completed`
- **Acceptance criterion:** synthetic overlap-interrupt emits exactly one repair cue, holds TTS position during LISTEN, plays repair audio after LISTEN without advancing original TTS, then resumes/completes the original utterance
- **Live hardware:** `data/m3_streaming_repair_live_20260509_072237/hardware_repair_validation.json` passed all repair-audio criteria
- **Boundary:** repair audio is supplied as pre-synthesized `StreamingConfig.repair_pcm`; live Broca synthesis should happen upstream, not inside the callback path. See `docs/m3_collision_repair_20260508.md`
