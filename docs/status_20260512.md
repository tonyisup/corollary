## M4 Per-Speaker Adaptive Threshold (2026-05-12)

**Problem:** Fixed M4 threshold (θ=0.10) produces 13-43 false positives per human speaker on BL-2021USB captures. ECAPA's frozen encoder maps self-TTS and human speech to overlapping embedding regions. No single threshold achieves 0 FP + ≥0.95 F1.

**Solution:** `SpeakerThresholdAdapter` tracks per-speaker M4 confidence distributions and raises the decision boundary for speakers whose confidence overlaps with the self region.

**Architecture:**
```
Audio → ThalamicAttributor.attribute(speaker_id=...)
  → M4 detector returns (is_self, confidence)
  → SpeakerThresholdAdapter.update(speaker_id, confidence)
  → threshold = max(base, speaker_max_conf + margin)
  → Gate: accepted if confidence >= threshold
```

**Key design decisions:**
- SELF frames always use base threshold (unaffected by other speakers)
- WORLD frames use per-speaker adaptive threshold
- Threshold adapts from frame 1 (no warm-up delay)
- Capped at max_threshold=0.50 to prevent blocking all self-detection
- Fully backward-compatible: speaker_id=None falls back to base threshold

**Results (6 BL-2021USB human speakers, feature-based fine-tuned scorer):**

| Speaker | WORLD conf range | FP (fixed θ=0.10) | FP (adaptive) | Self recall |
|---------|-----------------|-------------------|---------------|-------------|
| S1 | [-0.126, 0.182] | 24 | 0 | 92.4% |
| S2 | [-0.133, -0.040] | 4 | 0 | 92.4% |
| S3 | [0.180, 0.297] | 40 | 0 | 92.4% |
| S4 | [-0.036, 0.186] | 18 | 0 | 92.4% |
| S5 | [0.080, 0.292] | 42 | 0 | 92.4% |

- Training: 64 pairs, test accuracy: 93.75%
- Held-out replay F1: 0.81-0.91 (per speaker, fixed threshold)

**Comparison with full fine-tune:**
- Full fine-tune (5.4M unfrozen params, 50 epochs): test acc 87.5%, but F1=0.28 on held-out captures — overfit to training distribution
